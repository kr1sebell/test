# Тестовый проект

Этот репозиторий содержит два каркаса:

- минимальный Python‑пакет в каталоге `src/testproject` с тестами в `tests`
- заготовку React‑приложения в каталоге `frontend`

## Структура

- `src/testproject`: исходный код пакета
- `tests`: набор тестов для pytest
- `frontend`: клиентская часть на React

## Разработка

### Python

Запуск тестов:

```bash
pytest
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
